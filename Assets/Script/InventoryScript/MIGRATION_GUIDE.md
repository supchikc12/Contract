# ?? Инструкция по Миграции

## Что Нужно Сделать После Рефакторинга

### 1?? Обновить Префабы Ячеек

Все префабы ячеек инвентаря должны использовать компонент **`InventoryCell`** вместо `Grid`.

**Действия**:
1. Откройте префаб ячейки в Inspector
2. Удалите компонент `Grid` (если есть)
3. Добавьте компонент `InventoryCell`
4. Сохраните префаб

---

### 2?? Обновить Слоты Экипировки

Настройте визуализацию в `EquipmentSlot`:

**В Inspector для каждого EquipmentSlot**:
- Назначьте `Icon Image` - Image компонент для отображения иконки
- Назначьте `Icon Object` - GameObject с компонентом Image

---

### 3?? Проверить Слои

Убедитесь, что слои правильно назначены:
- **Слой 6**: Предметы (Items)
- **Слой 7**: Экипировка (Equipment Slots)

---

### 4?? Обновить Unity Editor

**Важно**: Перезагрузите проект Unity или обновите assets:
1. Вернитесь в Unity Editor
2. Нажмите `Ctrl+R` или `Assets > Refresh`
3. Дождитесь перекомпиляции

Это устранит ошибки компиляции, связанные с порядком загрузки классов.

---

### 5?? Проверить Компоненты на Префабах Предметов

Каждый префаб предмета должен иметь:
- `ItemState` - данные предмета
- `ItemInstance` - координатор логики
- `ItemView` - добавится автоматически, если отсутствует
- `CanvasGroup` - для управления прозрачностью при перетаскивании

---

## ?? Возможные Проблемы и Решения

### Проблема: "CS0246: Не удалось найти тип InventoryCell"

**Решение**:
1. Откройте Unity Editor
2. Нажмите `Ctrl+R` (Refresh)
3. Подождите завершения компиляции
4. Если не помогает - закройте Visual Studio/Rider, затем Unity, затем откройте заново

---

### Проблема: "Missing Reference в Inspector"

**Причина**: Ссылки на старый компонент `Grid` стали недействительными

**Решение**:
1. Откройте префаб с ошибкой
2. Удалите старые ссылки
3. Назначьте новые компоненты `InventoryCell`

---

### Проблема: "Предметы не перетаскиваются"

**Проверьте**:
1. `InventoryManager` находится на Canvas или на том же GameObject, что и Canvas
2. `GraphicRaycaster` есть на Canvas
3. `EventSystem` присутствует в сцене
4. Слои правильно назначены (6 и 7)

---

### Проблема: "Анимации не работают"

**Проверьте**:
1. Компонент `ItemView` добавлен на предмет
2. `CanvasGroup` присутствует

**Если отсутствует - добавьте вручную**:
- В Inspector на префабе предмета нажмите `Add Component`
- Найдите `Canvas Group`
- Добавьте компонент

---

## ?? Тестирование

### Что Протестировать:

1. **Перетаскивание из инвентаря в инвентарь**
   - Клик на предмет
   - Перемещение мыши
   - Отпускание в ячейке

2. **Поворот предмета (клавиша R)**
   - Во время перетаскивания нажмите R
   - Предмет должен повернуться на 90°

3. **Экипировка**
   - Перетащите предмет на слот
   - Должен экипироваться только подходящий тип

4. **Снятие экипировки**
   - Кликните на экипированный предмет
   - Должен начаться drag сразу

5. **Возврат на место**
   - Попробуйте положить предмет в неподходящее место
   - Должна быть анимация тряски и возврат

6. **Размещение рядом**
   - Попытайтесь положить предмет близко к занятой ячейке
   - Система должна найти ближайшую свободную
