# AI-ассистент в проекте (OpenCode + MCP для Unity)

Проект уже содержит всё нужное, чтобы ассистент мог читать и менять сцену Unity:
MCP-пакет лежит в `Packages/com.coplaydev.unity-mcp/`, конфиг — в `opencode.json`,
правила проекта — в `AGENTS.md`.

Настройка занимает ~5 минут и делается один раз на машину.

## Что нужно

- Windows 10/11
- **Unity 6000.0.22f1** (через Unity Hub)
- [OpenCode](https://opencode.ai) — десктопное приложение
- Интернет (только для установки `uv` и пакета MCP-сервера)

## Шаги

### 1. Установить OpenCode и войти

Установи OpenCode, открой его и выполни `/connect` — вход в аккаунт.
Модель `DeepSeek V4.1 Flash Free` бесплатна, отдельный ключ не нужен.

Если хочешь пользоваться моделями/квотой напарника — попроси приглашение
в его workspace (OpenCode Console → Members) и подключись к нему через `/connect`.

### 2. Запустить скрипт настройки

В PowerShell из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-ai.ps1
```

Что он делает:

1. ставит `uv` (менеджер Python-пакетов), если его нет;
2. добавляет `%USERPROFILE%\.local\bin` в PATH;
3. скачивает и прогревает MCP-сервер `mcp-for-unity`;
4. проверяет, что пакет MCP на месте;
5. переключает транспорт Unity на **stdio** (TCP 6400) — если Unity закрыт.

> Если Unity был открыт, скрипт попросит переключить транспорт вручную:
> `Window → MCP for Unity → Connection → Stdio`.

### 3. Открыть проект

1. Открой папку проекта в OpenCode (**File → Open Folder**, папка с `Assets/`).
2. Открой этот же проект в Unity.
3. Дождись окончания импорта и компиляции.

### 4. Проверить

Напиши в чат OpenCode:

```
Проверь связь с Unity: покажи активную сцену и иерархию
```

Ассистент должен ответить названием сцены и списком объектов. Если да —
можно работать: «создай куб…», «почини ошибку в консоли…», «сделай скриншот».

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `uvx: command not found` | Перезапусти OpenCode (PATH подхватывается только новым процессом) |
| Ассистент не видит Unity | Unity закрыт или ещё компилируется — подожди и повтори |
| `0 Unity instances` | Транспорт не stdio: `Window → MCP for Unity → Connection → Stdio`, затем перезапусти Unity |
| Порт 8080 занят | Это и есть причина, почему используется stdio — не переключай на HTTP |
| Пакет MCP не найден | Проверь, что папка `Packages/com.coplaydev.unity-mcp` есть в репозитории |

Логи MCP-сервера: `%LOCALAPPDATA%\UnityMCP\Logs\unity_mcp_server.log`.
Логи редактора Unity: `%LOCALAPPDATA%\Unity\Editor\Editor.log`.

## Правила совместной работы

- **Не редактируйте одну сцену одновременно.** `*.unity` — это YAML, git его
  не мержит как код. Разделяйте работу по сценам/префабам.
- Для мержа сцен можно включить `UnityYAMLMerge` (ставится вместе с Unity)
  как git mergetool.
- Контекст для ассистента — в `AGENTS.md`: если появляются новые системы,
  допишите туда пару строк, это дешевле, чем объяснять каждый раз.
- Секретов в репозитории нет и быть не должно: `opencode.json` содержит только
  команду запуска сервера, вход — per-user.

## Обновление MCP-пакета

Пакет вендорный, версия фиксированная:

1. Скачай новый релиз: `https://github.com/CoplayDev/unity-mcp/releases`
2. Замени содержимое `Packages/com.coplaydev.unity-mcp/` (файл `package.json` — в корне папки)
3. Перезапусти Unity и проверь консоль

Текущая версия: **10.3.0**.
